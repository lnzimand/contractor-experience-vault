# Future Roadmap

This document contains hypotheses, not commitments.

V1 must earn the right to expand.

## V1 - Project Experience Vault

```text
Record
  ->
Evidence
  ->
Retrieve
  ->
Present
```

## V2 - Capture Automation

Potential capabilities:

- Email ingestion
- WhatsApp ingestion
- Bulk uploads
- OCR
- AI evidence classification
- Document metadata extraction
- Duplicate detection
- Suggested project association

Goal:

Reduce the work required to build the project history.

## V3 - Tender Evidence Engine

Potential capabilities:

- Upload tender/RFQ
- Extract experience requirements
- Search existing projects
- Recommend matching previous projects
- Generate experience schedules
- Assemble an evidence pack

Goal:

Turn stored experience directly into bid preparation value.

## V4 - External Confirmation

Potential capabilities:

- Send client confirmation request
- Record confirmation state
- Reference-request workflow
- Confirmation history
- Signed attestations

Important:

Confirmation must be represented accurately and must not be marketed as independent verification unless a real verification standard/process exists.

## V5 - Portable Contractor Reputation

Possible longer-term model:

```text
Contractor
   |
   +-- Project history
   +-- Client-confirmed projects
   +-- Evidence
   +-- Categories / capabilities
   +-- Recorded project values
   +-- References
```

Potential users beyond the contractor:

- Procurement teams
- Principal contractors
- Financiers
- Insurers
- Suppliers
- Customers

This would be a materially different product and business model from V1.

## Other possible extensions

Only investigate if customer demand appears:

- Warranty / handover records
- Project close-out packs
- Compliance-document links
- Partner integrations
- Public project portfolios
- CRM/tender-platform integrations
